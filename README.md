# SE3082 – Start here

## Get your private project repository

1. Sign in to GitHub (create a free account first if you don't have one).
2. Open this link: **https://github.com/se3082-july/start-here/issues/new?template=get-my-repo.yml**
3. Tick the confirmation box and click **Create**.
4. Within about a minute a bot replies with a link. Open it and click **Accept invitation**.
5. Clone your repo and start working:

```bash
git clone https://github.com/se3082-july/hello-world-<your-github-username>.git
```

Your repository is private: only you and the SE3082 instructors can see it. You cannot see other students' repositories.

If anything goes wrong, contact your instructor. Please don't open more than one request.
