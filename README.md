# SE3082 – Start here

## Get your private Assignment 03 repository

1. Sign in to GitHub (create a free account first if you don't have one).
2. Open this link:
   **https://github.com/se3082-july/start-here/issues/new?template=get-my-repo.yml**
3. Enter your **student ID** (e.g. `IT24999938`), tick the confirmation box and click **Create**.
4. Within about a minute you will receive an invitation email. Accept it, or open
   `https://github.com/se3082-july/se3082-a3-<StudentID>/invitations` and click **Accept invitation**.
5. Clone your repository and follow the README inside it:

```bash
git clone https://github.com/se3082-july/se3082-a3-<StudentID>.git
```

Your repository is **private**: only you and the SE3082 instructors can see it. You can commit
and push, but you cannot delete it, make it public, or add other people.

For privacy, your request is deleted automatically once your repository has been created.

**Request only once.** If you made a mistake, or nothing arrives within 10 minutes, contact the
module coordinator. Do not open more requests.
